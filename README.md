# USB 网盘（行空板 M10）

把行空板变成一个小型文件服务：插上 U 盘，手机或电脑用浏览器就能浏览、下载、上传、复制文件。
板子上那块屏也做成了控制台 —— 显示服务状态、访问口令、各类访问地址，点右上角 ✕ 退出。

```
手机/电脑浏览器  ──WiFi──┐
                        ├──→  行空板 :8090  ──→  U 盘 /media/sda1
电脑 USB 直连    ──USB───┘
```

---

## 1. 为什么做这个

行空板的 USB-C 连着电脑时会建一条虚拟网卡，板子固定是 `10.1.2.3`。
这条链路比板子的 2.4G 单频 WiFi 快得多，传文件很合适 —— 但得有个文件服务。

于是有了这个网盘：**零依赖**（只用 Python 3.7 标准库），因为板子上装包不一定方便。

## 2. 依赖

**服务本体：无。** 只用 Python 3.7 标准库（`http.server` / `shutil` / `urllib`）。
**板载界面：** 板子自带的 `unihiker` GUI 库。

## 3. 部署

两个文件拷到板子上（SSH 工具或 Samba 都行）：

```
/root/M10_NetDisk/server.py    # 服务本体
/root/M10_NetDisk/ui.py        # 板载控制界面（可选）
```

## 4. 使用

### 4.1 只用服务（SSH 里跑）

```bash
cd /root/M10_NetDisk
python3 server.py                    # 默认 8090 端口
python3 server.py 9000               # 换端口
python3 server.py --root /root/share # 额外共享一个目录
python3 server.py --list             # 只列出可共享的存储，不启动
```

启动后打印访问口令和地址：

```
可访问的存储：
  U盘 sda1 (sda1)           /media/sda1

访问口令：见程序生成的 `token.txt`
（已存进 /root/M10_NetDisk/token.txt，下次启动沿用）

用浏览器打开（第一次要带口令）：
  http://10.1.2.3:8090/?k=<你的口令>
  http://<你的局域网IP>:8090/?k=<你的口令>
```

### 4.2 带板载界面（推荐，屏幕上能看状态）

```bash
cd /root/M10_NetDisk
DISPLAY=:0 XAUTHORITY=/var/run/lightdm/root/:0 python3 ui.py
```

界面会自动把服务拉起来。

| 操作 | 作用 |
|---|---|
| **A 键** | 启动 / 停止服务 |
| **B 键** | 切换「状态页」和「日志页」 |
| **点右上角 ✕** | 退出界面（会一并停掉服务） |

> ⚠️ 界面是**全屏**的，会盖住板子的 Home 菜单 —— 板子自带的 Home 键可以直接退出。
> 之所以还留个 ✕，是因为不能假设用户一定知道 Home 键能退。

### 4.3 浏览器里能做什么

| 功能 | 怎么用 |
|---|---|
| 浏览目录 | 点文件夹名 |
| 下载文件 | 点文件名 |
| 上传 | 页面底部选文件（可多选）→「上传到当前目录」 |
| **复制** | 勾选条目 → 填目标文件夹 →「复制」 |

**复制**支持文件和目录（递归），**重名不覆盖** —— 自动加 `(2)` `(3)` 后缀。
目标文件夹不存在会自动创建。

## 5. 配置

改 `server.py` 顶部的常量：

```python
PORT = 8090                              # 监听端口
MAX_UPLOAD = 2 * 1024 * 1024 * 1024      # 单文件上限（默认 2GB）
USB_MOUNT_DIRS = ["/media", "/mnt", ...] # 扫描 U 盘的目录
```

**额外共享某个目录**（默认只共享 U 盘，不碰系统目录）：

```bash
python3 server.py --root /root/shared
```

> 为什么默认不共享 `/root` 或 `/`？那里有配置、密钥、`.vscode-server` 之类的东西，
> 挂到局域网上等于全公开。要共享必须显式指定。

## 6. 安全

| 措施 | 说明 |
|---|---|
| **访问口令** | 首次启动随机生成 12 位，存 `token.txt`（权限 600），浏览器记住 7 天 |
| **存储根白名单** | `?r=` 参数必须匹配已知存储根，否则 403。防 `?r=/etc` 这种越权浏览 |
| **路径穿越防护** | `safe_join()` 挡 `../`；上传只取文件名，防止写到别处 |
| **默认不共享系统目录** | 见上 |

口令在地址里带一次（`?k=xxx`）之后，浏览器会记在 Cookie 里，以后直接开 `http://10.1.2.3:8090/`。

**口令泄露了怎么办**：删掉 `token.txt` 重启，会重新生成一个。

## 7. 已知限制

- **不支持断点续传。** 服务端忽略 `Range` 头，大文件传到一半断了只能重来。
  2.4G WiFi 下体验会比较糟。要加的话大约 20 行。
- **上传是同步的。** 拷大文件时浏览器一直转圈，没有进度反馈。
- **无 HTTPS。** 局域网内用，明文传输，别拿到公网上。

## 8. 文件说明

```
server.py    HTTP 服务本体（零依赖）
ui.py        板载控制界面（需要 unihiker GUI 库）
token.txt    自动生成的访问口令（不进版本库）
docs/        界面截图
```

## 9. 排错

| 现象 | 原因 / 处理 |
|---|---|
| 浏览器打不开 | 确认服务在跑：`netstat -tln \| grep 8090` |
| 一直弹 401 | 地址后面要带 `?k=口令`；口令看 `token.txt` 或板子屏幕 |
| 板子屏幕是黑的 | 界面没启动，或被别的程序盖住了。SSH 里 kill 掉别的界面程序 |
| 看不到 U 盘 | `lsblk` 确认挂上了；挂载点要在 `USB_MOUNT_DIRS` 覆盖的范围内 |
| 提示 403 | 访问的位置不在白名单里。要用 `--root` 显式添加 |
